
# Sample Sales Data Generation for EDA

## Project Overview
This project generates a realistic sample sales dataset
for practicing Exploratory Data Analysis (EDA) using Python.

## Dataset Details
- Total Records: 100,000
- Total Columns: 9
- Date Range: 2023–2024
- Missing Values: 5% in price and 2% in region.

## Technologies Used
- Python 3.10
- Pandas
- NumPy

## Project Files
- generate_sales_data.py
- sales_data.csv
- requirements.txt
- .gitignore

## How to Run

1. Create a virtual environment.
2. Install dependencies:

   pip install -r requirements.txt

3. Generate the dataset:

   python generate_sales_data.py

## Output
The generated dataset is saved as sales_data.csv.
